# Privacy Policy for Spet@Term

Last updated: November 12, 2026

Spet@Term ("the Application") is an open-source terminal emulator and universal file explorer developed by SpetGames. This Privacy Policy explains our practices regarding user data and privacy.

---

## 1. Summary

Spet@Term is designed with a strict privacy-first philosophy. **We do not collect, store, transmit, process, or sell any personal data, usage analytics, or telemetry of any kind.** The application operates entirely locally on your Windows device.

---

## 2. Information We Do Not Collect

- **Personal Information:** Spet@Term does not request, collect, or store personal identifiers such as your name, email address, IP address, device identifier, or location.
- **Terminal Inputs & Commands:** Any command, script, argument, or text typed or executed within Spet@Term is processed strictly on your local machine using the native Windows ConPTY subsystem. No command history or terminal output is ever transmitted over the network.
- **File Contents & Archives:** When you browse, inspect, preview, or extract archives (ZIP, RAR, 7Z, ISO, WAD, PK3, etc.) or 3D models (glTF, GLB), all processing takes place entirely in local memory and disk storage. No file metadata, filenames, or file contents are uploaded or shared.
- **Telemetry and Analytics:** The application contains zero telemetry SDKs, zero crash reporters, and zero tracking mechanisms.
- **Cookies & Trackers:** Spet@Term does not use cookies, advertising identifiers, or tracking scripts.

---

## 3. Network Usage

Spet@Term does not connect to any remote server, cloud service, or third-party API.

The only network activity that may occur while using Spet@Term is network activity explicitly initiated by you through your chosen command-line shell (for example, if you run `curl`, `git clone`, `ping`, or similar commands in PowerShell, Command Prompt, or WSL). Such traffic is governed by the respective tools and network destinations you choose to interact with, not by Spet@Term.

---

## 4. Third-Party Services and Libraries

Spet@Term is built as a native Win32 application utilizing native Windows APIs (Direct2D, DirectWrite, Direct3D 11, Windows Media Foundation, ConPTY). It does not embed any third-party analytics libraries, advertising frameworks, or external telemetry services.

---

## 5. Security

Because Spet@Term does not collect, transmit, or store any personal information on external servers, there is no remote database or server-side data that could be exposed, leaked, or breached.

---

## 6. Open Source Transparency

The complete source code of Spet@Term is publicly available for inspection, audit, and verification at:
https://github.com/Spet001/Spet-Term

---

## 7. Contact Information

If you have any questions or concerns regarding this Privacy Policy, you can open an issue on the official GitHub repository:
https://github.com/Spet001/Spet-Term/issues

---

# Política de Privacidade (Português - pt-BR)

Última atualização: 12 de novembro de 2026

O Spet@Term ("o Aplicativo") é um emulador de terminal e explorador universal de arquivos de código aberto desenvolvido pela SpetGames. Esta Política de Privacidade descreve as práticas em relação à privacidade e aos dados do usuário.

---

## 1. Resumo

O Spet@Term foi construído sob uma diretriz estrita de privacidade. **Nós não coletamos, não armazenamos, não transmitimos, não processamos e não vendemos nenhum dado pessoal, telemetria ou métrica de uso.** O aplicativo funciona de maneira 100% local no seu computador com Windows.

---

## 2. Dados Que Não Coletamos

- **Dados Pessoais:** O Spet@Term não solicita, não coleta e não armazena identificadores como nome, e-mail, endereço IP, identificador de dispositivo ou localização.
- **Comandos e Entradas do Terminal:** Qualquer comando, texto ou script executado no Spet@Term é processado estritamente de forma local no seu computador através do subsistema ConPTY do Windows. Nenhum histórico de comandos ou texto do console é enviado para a internet.
- **Arquivos e Documentos:** Ao navegar, inspecionar, extrair arquivos compactados (ZIP, RAR, 7Z, ISO, WAD, PK3, etc.) ou modelos 3D (glTF, GLB), todo o processamento ocorre exclusivamente na memória RAM e no disco rígido local. Nenhum conteúdo de arquivo ou metadado é compartilhado.
- **Telemetria e Estatísticas:** O aplicativo não contém SDKs de telemetria, relatórios de falhas automáticos ou ferramentas de rastreamento.
- **Rastreadores:** O aplicativo não utiliza cookies nem identificadores publicitários.

---

## 3. Uso de Rede

O Spet@Term não se conecta a nenhum servidor remoto, serviço em nuvem ou API externa.

Qualquer atividade de rede durante o uso do terminal ocorre exclusivamente quando você mesmo executa intencionalmente um comando que acesse a internet no shell (como `curl`, `git clone` ou `ping` no PowerShell, CMD ou WSL).

---

## 4. Bibliotecas de Terceiros

O Spet@Term é um software Win32 nativo construído com APIs do próprio sistema operacional Windows (Direct2D, DirectWrite, Direct3D 11, Windows Media Foundation, ConPTY). Ele não incorpora ferramentas de análise de terceiros ou frameworks de publicidade.

---

## 5. Transparência e Código Aberto

O código-fonte integral do Spet@Term é público e auditável em:
https://github.com/Spet001/Spet-Term

---

## 6. Contato

Para dúvidas sobre esta política de privacidade, você pode abrir uma issue no repositório oficial do projeto:
