## 3. Description
Spet@Term is a native, GPU-accelerated Windows terminal emulator that integrates a universal game asset archive explorer and an interactive 3D media viewer.

Built from scratch in C++20 using Win32, Direct2D, and DirectWrite APIs, Spet@Term delivers sub-50ms startup times and a lightweight memory footprint, completely free of Electron, NodeJS, or browser runtime overhead.

### GPU-Accelerated Terminal
- Comprehensive terminal emulation with native ConPTY support.
- Native compatibility with PowerShell, Command Prompt (CMD), and WSL Linux distributions.
- Crisp, low-latency text rendering accelerated by Direct2D hardware pipelines.
- Integrated hardware resource monitor showing real-time CPU, RAM, and GPU utilization.

### Universal Game File & Archive Explorer
- Native browsing and extraction for game archive formats: WAD (Doom), PK3 and PAK (Quake), VP (Descent), VPK (Source Engine), MPQ (Blizzard), BIG, GCF, and Xbox 360 ISO discs.
- Broad compression archive support: ZIP, ZIP64, RAR (including multipart .part1/.part2 archives), 7Z, ISO disc images, and Windows app packages (AppX, MSIX).
- Custom desktop context menu with quick navigation, direct extract-to-folder actions, and standard file operations.

### Interactive 3D, Audio, and Video Previews
- Integrated Direct3D 11 model inspector for glTF and GLB 3D files with orbit rotation, pan, zoom, and wireframe toggle.
- Native audio and video playback using Windows Media Foundation for MP4, MP3, WAV, OGG, and FLAC files.
- Live looping video wallpaper engine running seamlessly behind the terminal workspace.

### Built-in Text Editor & Retro Aesthetic
- Lightweight text and code editor for rapid inspection and editing of scripts (.ps1, .bat, .sh), config files (.ini, .json, .xml), and source code.
- Customizable interface inspired by the classic Windows 98 desktop aesthetic with an optional CRT scanline display filter.
