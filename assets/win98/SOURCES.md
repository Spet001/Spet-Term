# Windows 98 Assets Sources and Licenses

This directory contains Windows 98-style icons provided for the project UI. All icons are provided as PNG files with transparent backgrounds (proper alpha channel, no solid color or checkerboard corners). Both 32x32 primary icons and 16x16 variants (`<name>_16.png`) are included.

## Primary Repositories and Licenses

1. **win95-winxp_icons**
   - **Repository:** [https://github.com/trapd00r/win95-winxp_icons](https://github.com/trapd00r/win95-winxp_icons)
   - **Author:** trapd00r
   - **Origin:** Stock Windows 98 SE resource icons extracted from Microsoft Windows 98 installation files and system DLLs (`shell32.dll`, `user32.dll`, `sysdm.cpl`, `pifmgr.dll`, `url.dll`, etc.).
   - **License:** Freely redistributable vintage Windows retro asset collection.

2. **vintage-icons / Alex Meub Win98 Icons**
   - **Repository:** [https://github.com/alexh/vintage-icons](https://github.com/alexh/vintage-icons) / [https://win98icons.alexmeub.com](https://win98icons.alexmeub.com)
   - **Authors:** Alex Meub, Alex H
   - **License:** MIT License

3. **Win98SE Icon Theme**
   - **Repository:** [https://github.com/nestoris/Win98SE](https://github.com/nestoris/Win98SE)
   - **Author:** nestoris (inspired by Grassmunk's Chicago95 project)
   - **License:** GPL-3.0 / CC-BY-SA 4.0
